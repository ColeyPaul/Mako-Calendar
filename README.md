# 🦈 Vista Del Mar 1st Grade Mako Sharks Community Calendar

An unofficial, community-managed hub for Vista Del Mar (VdM) school events, minimum days, class parties, spirit days, and holidays—automated directly from Capo USD school emails, Mako Messenger newsletters (Smore), and room parent updates.

---

## 🌟 Features

- **Automated Email & Newsletter Ingestion**: Parses official school update emails and Constant Contact newsletters.
- **Smore Newsletter Parser**: Detects and extracts Smore newsletter issue links automatically.
- **One-Click Calendar Sync**: Parents can auto-sync events to Google Calendar, Apple Calendar, or Outlook.
- **Community Event Submissions**: Form integration allowing parents and room parents to submit class party dates or missing events.
- **Cloud-Based "Set-it-and-Forget-it"**: Powered by a Google Apps Script daily cloud trigger running automatically.

---

## 🤖 How the Automation Works

1. **Google Apps Script Trigger**: Runs daily between 8:00 AM – 9:00 AM in Google Cloud.
2. **Email & Smore Link Extraction**: Searches recent messages for school updates, extracts dates, minimum day schedules, and Smore links.
3. **Calendar Auto-Update**: Updates the shared Google Calendar automatically.
